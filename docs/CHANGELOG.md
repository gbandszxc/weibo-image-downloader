# 更新日志

> 本文件记录各版本变更，新条目追加在顶部。发布新版本时随 Git tag 一起更新。

### v1.5.0
- 新增：X 动图（GIF）默认自动转换为循环播放的 `.gif` 下载，可在脚本菜单关闭；转换保留源尺寸与时长，通过重复帧合并与差分压缩无损减小体积，转换失败自动回退提示可下载 `.mp4` 源
- 新增：下载按钮持续显示"下载中 / 完成 / 失败 / 已发起"状态并平滑调整宽度，同帖执行期间防重复点击
- 优化：GIF 转换支持最多两个 Web Worker 并行量化编码、OffscreenCanvas 离屏绘制帧，转换耗时约降低 40%，主线程长任务基本消除，减少页面滚动卡顿
- 修复：X 详情页等媒体渐进加载场景下，下载按钮计数与 GIF 类型自动校正，列表页与详情页行为一致；GIF 徽标未及时渲染时不再误下载 `.mp4`
- 修复：X 公开媒体 CDN 拒绝带凭据请求导致下载回退失败，现按平台省略凭据
- 修复：微博纯文字等 DOM 无图帖子不再闪现下载按钮，改为接口确认有媒体后才插入按钮
- 修复：微博文章类帖子的封面图不再被误认为可下载图片，避免按钮闪现后消失

### v1.4.4–v1.4.7
- 修复：X 含引用图片的普通视频帖子会正确查询当前帖，并从接口补全尚未载入 DOM 的引用图片
- 优化：混合图片与视频下载完成后，会分别提示图片和视频数量

### v1.4.3
- 新增：实验性支持微博 / X 平台视频下载（需手动开启设置，并授予相应权限）

### v1.4.2
- 新增：移动端微博适配
- 修复：微博详情页点击下载按钮，弹出图片数量新标签不执行下载行为
- 修复：Tampermonkey `@connect` 改为根域名声明，兼容微博图片子域名下载
- 修复：补充 `@connect *` 兜底，兼容微博图片下载中的重定向与未预料域名校验

### v1.4.1
- 修复：X 动图（GIF）改为下载可播放的 `.mp4` 动图源，不再误下成 `.jpg` 缩略图

- 修复：X 时间线、用户页、详情页统一使用时间锚点注入下载按钮，减少详情页按钮丢失问题

### v1.4.0
